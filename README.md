# Shadow Ascension

A browser-based 3D-style dungeon action game built with Three.js.

## Current systems
- Cinematic title / awakening screen
- 3D dungeon environment with fog, lighting, shadows and arena walls
- Third-person-style player character and weapon
- Shadow enemies and elite enemies
- Real-time melee combat
- Shadow Slash, Shadow Burst and Shadow Step abilities
- HP, XP, levels and scaling health
- Multi-floor dungeon waves
- Dungeon objective and progress HUD
- Particle effects and combat feedback
- Responsive desktop/mobile HUD
- Mobile touch movement controls
- Runs as a static website; Three.js is loaded from a CDN

## Run
Open `index.html` in a modern browser. For best results use a local/static web server so browser security restrictions do not interfere with future assets.
